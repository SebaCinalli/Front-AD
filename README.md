# Front-AD — Sistema de Gestión y Reserva de Eventos (TP-DSW)

Aplicación web SPA desarrollada con **React 19, TypeScript, Vite 7 y React Router v7**.

- **Aplicación Producción:** https://front-ad-2.onrender.com
- **Backend API:** https://back-ad-3.onrender.com ([Repositorio Back-AD](https://github.com/SebaCinalli/Back-AD))

## Inicio Rápido

```bash
pnpm install
pnpm dev            # Desarrollo (http://localhost:5173)
pnpm build          # Compilar para producción
pnpm test           # Tests unitarios de componentes (Vitest + Testing Library)
pnpm run test:e2e   # Test End-to-End en Chrome (Playwright)
```
